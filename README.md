# 🌌 Beyond the Stars

Explore the beauty and mysteries of the universe through stunning astronomical imagery from NASA's Astronomy Picture of the Day (APOD).

## ✨ About the Project

**Beyond the Stars** is a web application designed to showcase extraordinary images of the universe. It allows users to discover astronomical photography, explore curated highlights, and search for images by date.

The project was built to practice front-end development, API integration, and responsive interface design.

## 🚀 Features

* **Home Page:** Discover selected astronomical images and the picture of the day.
* **Cosmos Gallery:** Browse a collection of curated images from the universe.
* **Explore by Date:** Search for astronomical images using a specific date.
* **Image Details:** View image titles, dates, descriptions, and credits.
* **Responsive Design:** An interface designed for different screen sizes.

## 🛠️ Technologies

* React
* JavaScript
* Tailwind CSS
* React Router
* Lucide React
* NASA APOD API

## ⚙️ Getting Started

### Prerequisites

* Node.js
* npm
* A NASA API key

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/BrunaBeatriiz/cosmos-gallery.git
   ```

2. Navigate to the project directory:

   ```bash
   cd cosmos-gallery
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Create a `.env` file in the project root and add your NASA API key:

   ```env
   VITE_NASA_API_KEY=your_api_key
   ```

5. Start the development server:

   ```bash
   npm run dev
   ```

## 🌠 Data Source

Astronomical images and related information are provided by NASA's Astronomy Picture of the Day (APOD).

* [NASA APOD](https://science.nasa.gov/solar-system/astronomy-picture-of-the-day/)
* [NASA API Portal](https://api.nasa.gov/)
